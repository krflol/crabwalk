# Crabwalk Compatibility and Verification

## Supported release matrix

| Dimension | Policy |
|---|---|
| Python | CPython 3.11–3.14; interpreter-specific extension ABI |
| Rust | pinned release toolchain 1.97.0; Miri uses pinned nightly-2026-08-01 |
| PyO3 | pinned to 0.29.2 with `extension-module` and macOS link setup |
| OS | Windows, Linux, and macOS in the required native matrix |
| Profile | Cargo release profile, overflow checks, forced unwind panic strategy |
| Source unit | module, regular package, or configured namespace package |
| Application wheel | one or more configured top-level packages; CPython/platform specific |

Crabwalk's compiler/runtime distribution is pure Python. Generated application
artifacts remain interpreter-, operating-system-, architecture-, and extension-
ABI-specific. A matching wheel consumer does not need Cargo, rustc, or a linker.

Application manifests separate distribution version, runtime ABI,
generated-wrapper ABI, manifest schema, IR schema, and codegen schema. A compatible
1.1 patch runtime may load an artifact generated by another 1.1 patch when the
protocol identities and source/artifact hashes match; incompatible ABI values fail
before native loading.

## Test layers

```text
tests/unit/
  package graph, declarations, typed IR, lowering, ownership, effects, ABI shapes
  deterministic Rust/Cargo generation and rustc-backed identifier oracle
  boundary codecs, recursive domains, HashMap, TextColumn, Shared, telemetry
  cache/fingerprint/lock/prune/cancellation behavior
  PEP 517 metadata/sdist/wheel structure and developer-tooling protocols

tests/integration/
  native execution, recursion, GIL behavior, panic and structured Result errors
  ownership/move/borrow/reload/GC/thread/failure-atomic lifecycle
  recursive domains, 100k bulk rows, mapping input, TextColumn, Shared handles
  sequential/Rayon pipelines, native ETL, traits/generics/operators/closures
  typed Python and Cargo-crate adapters
  dependency/cache races, unsafe containment, package/re-export behavior
  virtual multi-module embedding and hard Cargo cancellation
  clean regular/namespace multi-package PEP 517 wheel install without Rust
```

Run the static/unit gate:

```powershell
python -m ruff format --check src tests examples scripts benchmarks
python -m ruff check src tests examples scripts benchmarks
python -m mypy
python -m pyright tests/unit/test_typing_distribution.py
python -m pytest tests/unit -q
```

Run the execution-backed release suite:

```powershell
crabwalk doctor
python -m pytest -q `
  --enforce-capability-contracts `
  --capability-evidence=.crabwalk/reviews/capability-evidence.json
```

Run the versioned performance/lifecycle gate:

```powershell
python benchmarks/run_release_gate.py `
  --output .crabwalk/reviews/performance.json
```

The budgets live in `benchmarks/performance_budgets.json`. The report records
Python/platform/rustc/Cargo identity, cold and warm process time, 10/1k/100k nested
construction/call phases, retained RSS growth, boundary crossings, allocations,
values, bytes copied, and clones. The tag workflow reruns this gate and attaches the
report plus its SHA-256 to the GitHub release.

## Evidence rules

- Native execution is proven through loaded extension behavior, generated Rust
  call edges, subprocess isolation, and GIL-progress tests—not timing alone.
- A capability contract is satisfied only by an actually collected and passing
  pytest item. Skip/xfail-only or source-text presence is not evidence. Each native
  matrix lane publishes a machine-readable manifest.
- Cache hits require manifest and binary verification plus Cargo validation.
  Corruption rebuilds, simultaneous publishers converge, and mapped extensions
  survive pruning.
- A compile failure passes only when its primary diagnostic maps to Python source
  and preserves bounded relevant rustc detail.
- Wheel evidence builds a runtime wheel and metadata-rich application wheel,
  resolves the runtime dependency normally in a clean venv, removes Rust/Cargo
  from `PATH`, runs every embedded package, and verifies no consumer workspace.
- Rust Book chapter coverage is pedagogical. Capability maturity is generated from
  the compiler registry and its executable contract IDs.
- Exact release portability is established only by the protected tag workflow on
  the immutable candidate SHA.

## Local 1.1.1 release-candidate evidence

On 2026-09-01, the release candidate was exercised on CPython 3.11.8,
Windows x86-64, and rustc/Cargo 1.97.0:

- **421 unit tests** passed;
- **70 integration tests** passed, for **491 tests total** and all **77 executable
  capability contracts**;
- Ruff formatting/lint passed across 203 Python files;
- mypy passed across all 47 configured core source modules, including frontend,
  runtime, Rust surface, CLI, loader, inspection, LSP, telemetry, and tooling;
- the public PEP 561 consumer smoke passed Pyright with zero diagnostics;
- a real PEP 517 sdist and wheel containing both a regular and namespace package
  built successfully; the wheel installed through normal offline dependency
  resolution and its console-script entry point ran both native modules with
  Cargo/rustc absent;
- the Miri contract crate passed ordinary stable tests locally; the tag workflow
  runs it under pinned nightly Miri;
- the versioned performance gate passed with no violations: 25.11s cold process,
  9.36s warm process, 8.50s warm 100k nested-row construction, 0.025s native
  call, 21,590,016 bytes retained RSS growth, one crossing, and zero native
  clones; and
- generated capability documentation, Python byte compilation, structured-error,
  100k-domain, Shared reload/GC/shutdown, virtual-package embedding, cancellation,
  and unsafe/panic subprocess regressions passed.

These numbers describe this local machine and fixture, not universal application
performance. The exact final tag must still pass the complete Windows/Linux/macOS
matrix for CPython 3.11 and 3.14, the 3.12/3.13 unit lanes, quality/generated-Rust
checks, Miri, performance budgets, artifact smoke installs, and Trusted Publishing
workflow before 1.1.1 is considered released.
